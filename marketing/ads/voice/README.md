## Before you run these

- **Free or paid.** Videos 01 to 06 promote free courses and are safe to run at any time. Videos 07 to 10 promote paid courses and show no price. The courses they send people to must have **enrolment open** in the admin (Courses → the course → enrolment), or visitors will see "Enrolment opens soon". Check the link for each before you spend.
- **No promises of income or jobs.** The scripts describe what the courses teach. Please do not edit them to promise a job, a salary or guaranteed results; Meta and Google reject that, and it would not be true.
- **The voice.** It is a computer voice (Microsoft neural text to speech, Nigerian English: Ezinne for the female voice and Abeo for the male voice). Some platforms ask you to label synthetic voices or AI-generated content; check the current rules in the ad manager and tick the disclosure if it asks. If you want a human voice later, record the scripts above and keep the same on-screen text.
- **Listen once before you publish.** Computer voices occasionally stress a word oddly. If you hear one, edit the spelling of that line in `specs.py` (for example "A I" and "C V" are spelled out so they are read as letters) and rebuild that video.
- **Music.** There is none, on purpose. Add trending or licensed music inside Instagram, CapCut or the ad editor, at a low volume under the voice.
- **Test small.** Run two or three of these for a week at a small daily budget, compare, and keep the winner (see `../README.md`).

## Rebuilding or changing a video

The videos are code. Wording, voice and timing are in `specs.py`; the look is in `template.html` (and `../video/video.css`).

```
pip install edge-tts imageio-ffmpeg
python marketing/ads/voice/build.py all                      # all ten
python marketing/ads/voice/build.py 03-sql-in-browser        # one
```

It needs Chrome and Playwright (set `CHROME` and `PLAYWRIGHT_PATH` if they are not found). The script text is sent to Microsoft's online voice service to be turned into speech, so it needs an internet connection. Scene lengths follow the length of the speech, so changing the words changes the timing automatically.
